# 🌾 Rice Leaf Disease Detection

This project uses *Convolutional Neural Networks (CNN)* to detect and classify rice leaf diseases using image data.  
The goal is to help farmers identify crop diseases early and minimize agricultural losses through technology-driven insights.

## 🚀 Project Overview
- Built a *CNN model* using TensorFlow and OpenCV to classify rice leaf diseases.  
- Trained on *5,000+ images* of healthy and diseased leaves.  
- Achieved *95% accuracy* in disease detection.  
- Implemented *data augmentation* and preprocessing for better performance.

## 🧠 Technologies Used
- *Python*
- *TensorFlow / Keras*
- *OpenCV*
- *NumPy, Pandas, Matplotlib*
- *Google Colab / Jupyter Notebook*

## 📊 Results
- Training Accuracy: 95%  
- Validation Accuracy: 93%  
- Successfully classified rice leaf diseases such as leaf blast, brown spot, and bacterial blight.
